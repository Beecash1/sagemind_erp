# SageMind ERP

SageMind ERP is an AI-powered multi-tenant SaaS ERP/CRM platform designed to help organizations manage business operations, customer relationships, inventory, tasks, analytics, and intelligent business workflows from a unified system.

The platform is built using modern scalable architecture with Next.js, NestJS, PostgreSQL, and Prisma, focusing on enterprise-grade modularity, tenant isolation, role-based access control, and AI-assisted business insights.

## Core Features

- Multi-tenant SaaS architecture
- Role-Based Access Control (RBAC)
- CRM and customer pipeline management
- Task and workflow management
- Inventory and product management
- Branch and staff management
- Analytics dashboard
- AI-powered business insights and recommendations
- RESTful API architecture
- Scalable modular backend structure

## Tech Stack

### Frontend
- Next.js
- TypeScript

- shadcn/ui

### Backend
- NestJS
- Prisma ORM
- PostgreSQL
- JWT Authentication

### AI Integration
- OpenAI API

## Architecture Goals

SageMind ERP is designed with:
- scalable SaaS principles,
- clean modular architecture,
- secure tenant isolation,
- maintainable API structure,
- and intelligent automation capabilities.

The project also serves as a research-oriented implementation exploring AI-assisted analytics and predictive business workflows within multi-tenant enterprise systems.
